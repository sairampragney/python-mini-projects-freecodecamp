# Variables and Data Types

## Description

This project demonstrates the basic data types in Python by creating variables of different types and displaying their values and corresponding data types.

## Concepts Covered

- Variables
- String (`str`)
- Boolean (`bool`)
- Integer (`int`)
- Float (`float`)
- `type()` function
- `isinstance()` function

## How to Run

```bash
python variables_data_types.py
```

## Sample Output

```
Alice <class 'str'>
True <class 'bool'>
20 <class 'int'>
True
```

## Learning Outcome

This project helped me understand how Python stores different types of data and how to determine a variable's data type using the `type()` and `isinstance()` functions.
