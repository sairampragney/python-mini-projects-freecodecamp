# Employee Profile Generator

## Description

A beginner-friendly Python project that generates and displays an employee profile using variables, string operations, formatted strings, and string slicing.

## Concepts Covered

- Variables
- String Concatenation
- Augmented Assignment (`+=`)
- Type Conversion (`str()`)
- Formatted Strings (f-strings)
- String Slicing

## Files

- `employee_profile_generator.py` – Main Python program

## How to Run

```bash
python employee_profile_generator.py
```

## Sample Output

```text
John Doe is 28 years old
Experience: 5 years
Employee: John Doe | Age: 28 | Position: Data Analyst | Salary: $75000
DEV
2026
JD
```

## Learning Outcome

This project demonstrates how to manipulate strings, format output, convert data types, and extract information using string slicing in Python.
