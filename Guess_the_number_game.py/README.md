# Guess the Number

A simple Python console game where the player tries to guess a secret number between 1 and 10.

The program continues asking for guesses until the correct number is entered.

---

## 📌 About

This project was created as part of my **Python learning journey** to practice:

- Variables
- While loops
- Conditional statements
- User input
- Type conversion
- Comparison operators

The goal is to understand how loops and conditions can be combined to create a simple interactive program.

---

## 🎮 How It Works

1. A secret number is stored in the program.
2. The player is asked to guess a number from 1 to 10.
3. If the guess is incorrect, the program displays a message and asks again.
4. The loop continues until the correct number is guessed.
5. When the correct number is entered, the program displays a success message.
