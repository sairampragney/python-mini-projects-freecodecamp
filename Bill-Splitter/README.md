# Bill Splitter

## Description

A beginner-friendly Python project that calculates the total restaurant bill, adds a 25% tip, and determines how much each friend should pay.

## Concepts Covered

- Variables
- Arithmetic Operators
- Augmented Assignment (`+=`)
- Basic Calculations
- Output Formatting

## Files

- `bill_splitter.py` – Main Python program

## How to Run

```bash
python bill_splitter.py
```

## Sample Output

```text
Total bill so far: 198.83
Tip amount: 49.7075
Total with tip: 248.5375
Bill per person: 62.134375
```

## Learning Outcome

This project demonstrates how to perform arithmetic operations, update variables using augmented assignment, calculate percentages, and split a total bill equally among multiple people.
