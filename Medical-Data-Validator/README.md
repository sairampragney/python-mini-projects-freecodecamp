# Medical Data Validator

## Description

A beginner-friendly Python project that validates medical records and checks whether they follow the required data format and validation rules.

## Concepts Covered

* Functions
* Dictionaries
* Lists and Tuples
* Sets
* Regular Expressions (`re`)
* `isinstance()`
* Conditional Statements
* Loops
* List Comprehensions
* Dictionary Unpacking
* Data Validation

## Files

* `medical_data_validator.py` – Main Python program

## Validation Checks

The program validates:

* Patient ID format
* Patient age
* Gender
* Diagnosis
* Medication data
* Last visit ID
* Required dictionary keys
* Overall data structure

## Example

```python
validate(medical_records)
```

### Sample Output

```text
Valid format.
```

## Learning Outcome

This project helped me understand how to validate structured data in Python using dictionaries, lists, sets, regular expressions, functions, and conditional logic.
