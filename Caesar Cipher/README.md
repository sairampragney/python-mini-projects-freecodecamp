# Caesar Cipher

## Description

A beginner-friendly Python project that implements a Caesar cipher to encrypt and decrypt text by shifting letters through the alphabet.

## Concepts Covered

- Functions
- Function Parameters
- Conditional Statements
- String Manipulation
- String Slicing
- `str.maketrans()`
- `str.translate()`
- Encryption and Decryption
- Input Validation

## Files

- `caesar_cipher.py` – Main Python program

## Example

```python
encrypted_text = encrypt('freeCodeCamp', 3)
print(encrypted_text)
