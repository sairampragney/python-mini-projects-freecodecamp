# Movie Ticket Booking Calculator

## Description

A beginner-friendly Python project that simulates a movie ticket booking system. It determines ticket eligibility, applies discounts and extra charges, calculates service charges based on seat type, and evaluates booking conditions using conditional statements.

## Concepts Covered

- Variables
- Conditional Statements (`if`, `elif`, `else`)
- Comparison Operators
- Logical Operators (`and`, `or`)
- Nested Conditional Statements
- Basic Arithmetic

## Files

- `movie_ticket_booking_calculator.py` – Main Python program

## How to Run

```bash
python movie_ticket_booking_calculator.py
```

## Sample Output

```text
User is eligible to book a ticket
User is eligible for Evening shows
User does not qualify for membership discount
Discount: 0
Extra charges will be applied
Extra charges: 2
Ticket booking condition satisfied
Service charges: 3
```

## Learning Outcome

This project helped me understand how to use conditional statements, logical operators, and nested decision-making to implement a simple ticket booking system.
