# Build a Polygon Area Calculator

A Python object-oriented programming project that implements a `Rectangle` class and a `Square` class.

The `Square` class inherits from the `Rectangle` class and extends its behavior to represent a square.

The project also provides methods for calculating areas, perimeters, diagonals, generating text-based pictures, and determining how many smaller shapes can fit inside a larger shape.

This project was completed as part of my **FreeCodeCamp Python learning journey**.
