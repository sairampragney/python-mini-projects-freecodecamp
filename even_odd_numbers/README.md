# Even and Odd Numbers

A simple Python program that uses a `for` loop and conditional statements to separate numbers from `0` to `99` into **even** and **odd** numbers.

---

## 📌 About

This project is part of my **Python learning journey** and focuses on practicing basic programming concepts.

The program checks each number in a range and stores it in either an even-number list or an odd-number list.

### Concepts used

- Lists
- `for` loops
- `range()`
- `if` / `elif`
- Modulo operator `%`
- `.append()`
