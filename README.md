📘 About This Repository

This repository is a personal Python learning log — a collection of beginner-to-intermediate projects and coding exercises completed while learning Python through FreeCodeCamp's curriculum.

It is not a showcase of production-grade applications. It's a hands-on practice space where I apply each new concept by actually building something with it, rather than just reading about it.

A few things worth knowing about how this repo works:

Every project is based on an exercise or concept from FreeCodeCamp's Python coursework.
Each project lives in its own separate folder, with its own code and notes.
The focus is on learning by building — understanding concepts through repetition and practice, not perfection.
Code quality reflects where I was in the learning process at the time, so earlier projects may look simpler than later ones.
