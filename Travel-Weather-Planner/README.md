# Travel Weather Planner

## Description

A beginner-friendly Python project that determines the most suitable mode of travel based on distance, weather conditions, and available transportation options using conditional statements and logical operators.

## Concepts Covered

- Variables
- Boolean Values
- Conditional Statements (`if`, `elif`, `else`)
- Logical Operators (`and`, `or`, `not`)
- Comparison Operators

## Files

- `travel_weather_planner.py` – Main Python program

## How to Run

```bash
python travel_weather_planner.py
```

## Sample Output

```text
True
```

## Learning Outcome

This project helped me understand how to use Boolean values, logical operators, and conditional statements to make decisions based on multiple conditions in Python.
