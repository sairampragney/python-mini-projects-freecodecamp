# Pin Extractor

## Description

A beginner-friendly Python project that extracts secret PIN codes from poems by using the number of words in specific positions of each line.

## Concepts Covered

- Functions
- Lists
- Strings
- String Splitting
- Nested Loops
- `enumerate()`
- Conditional Statements
- String Manipulation
- `append()`

## Files

- `pin_extractor.py` – Main Python program

## Example

The program processes multiple poems and extracts a numeric code based on the number of words in each line.

## How to Run

```bash
python pin_extractor.py
