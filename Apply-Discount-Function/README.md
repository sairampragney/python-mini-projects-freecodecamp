# Apply Discount Function

## Description

A beginner-friendly Python project that defines a function to calculate the final price of an item after applying a percentage discount. The program also validates user input to ensure the price and discount values are valid.

## Concepts Covered

- Functions
- Parameters and Return Values
- Input Validation
- Conditional Statements (`if`)
- Type Checking (`isinstance()`)
- Arithmetic Operations

## Files

- `apply_discount.py` – Main Python program

## How to Run

```bash
python apply_discount.py
```

## Example

```python
print(apply_discount(50, 20))
```

### Sample Output

```text
40.0
```

## Learning Outcome

This project helped me understand how to create reusable functions, validate input, handle invalid data, and perform percentage-based calculations in Python.
