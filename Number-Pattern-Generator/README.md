# Number Pattern Generator

## Description

A beginner-friendly Python project that generates a sequence of numbers from `1` to a given positive integer. The program also validates the input to ensure that the argument is an integer greater than zero.

## Concepts Covered

* Functions
* Function Parameters
* Input Validation
* `isinstance()`
* Conditional Statements
* `for` Loops
* `range()`
* Lists
* `append()`
* String Conversion
* `join()`

## Files

* `number_pattern.py` – Main Python program

## Example

```python
number_pattern(5)
```

### Sample Output

```text
1 2 3 4 5
```

## Learning Outcome

This project helped me practice functions, loops, lists, input validation, and string manipulation in Python.
