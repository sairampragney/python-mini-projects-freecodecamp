# Debug an ISBN Validator

## Description

A Python project based on a FreeCodeCamp debugging lab. The program validates ISBN-10 and ISBN-13 codes by checking their length, characters, and calculated check digit.

The project focuses on debugging an existing program and handling common Python exceptions without crashing.

## Concepts Covered

- Functions
- String Manipulation
- Lists
- `enumerate()`
- Exception Handling
- `try` and `except`
- `IndexError`
- `ValueError`
- Conditional Statements
- String Slicing
- Input Validation
- ISBN-10 Check Digit
- ISBN-13 Check Digit

## Validation Features

The program handles:

- Invalid input format
- Missing comma-separated values
- Non-numeric ISBN length
- Invalid ISBN length
- Incorrect ISBN length
- Invalid characters
- Invalid check digits
- Valid ISBN-10 codes
- Valid ISBN-13 codes
